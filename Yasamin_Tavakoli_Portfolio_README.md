## Featured Work

### Fault-Tolerant Virtual Sensor for EV Battery Systems
**M.Sc. Thesis — Sharif University of Technology**

A deep-learning virtual sensor designed to estimate lithium-ion battery temperature and improve Battery Management System reliability when physical sensors become inaccurate or fail.

**Highlights:**
- BiGRU-based time-series model
- Two-stage nominal training and robust fine-tuning
- Fault-aware evaluation under transient and permanent sensor faults
- More than **8 million time-series samples**
- **1.59°C MAE** under nominal conditions
- **4,477 independent test files**
- Compact model footprint of approximately **1.7 MB**

**Technologies:** Python, PyTorch Lightning, BiGRU, Pandas, NumPy, Scikit-learn, time-series modeling

---

### Persian Sign Language Recognition
**B.Sc. Thesis — Computer Engineering**

An end-to-end Persian Sign Language recognition project covering original data collection, dataset creation, preprocessing, hand detection, deep-learning model training, and evaluation.

**Highlights:**
- Created a custom dataset of **4,070 images**
- Collected data from **36 participants**
- Covered **37 Persian Sign Language classes**
- Used MediaPipe for hand detection and cropping
- Compared ResNet18, ViT, and ResNet152
- Best result: **96.4% accuracy with ResNet152**

**Technologies:** Python, PyTorch, MediaPipe, ResNet18, ResNet152, Vision Transformer, Computer Vision

## Run Locally

No build step is required.

Clone the repository:

```bash
git clone https://github.com/ysmniall/ysmniall.github.io.git
cd ysmniall.github.io
```

Then open `index.html` directly in your browser, or run a simple local server:

```bash
python -m http.server 8000
```

Open:

```text
http://localhost:8000
```
